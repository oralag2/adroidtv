# Оновлення KinoTV 0.2.0

[Завантажити лише змінені файли](https://github.com/oralag2/adroidtv/raw/refs/heads/main/updates/kinotv-0.2-update.zip).

Якщо пряме посилання не працює, відкрийте `kinotv-0.2-update.zip` у цій папці на GitHub і натисніть **Download raw file**.

Архів містить 24 змінені та нові файли для оновлення початкової версії 0.1.0, включно з виправленням аварійного запуску на Android через регулярний вираз у `UaKinoParser.kt`. Повний проєкт, Android SDK та кеші не включені.

1. Скопіюйте вміст архіву в корінь наявного проєкту, де розташований `settings.gradle.kts`.
2. Збережіть структуру папок і підтвердьте заміну відповідних файлів. Якщо ви самостійно редагували ці файли, спочатку збережіть свої правки окремо.
3. Файл `local.properties` зі шляхом до вашого SDK не входить до архіву й залишається без змін.
4. В Android Studio виконайте **File → Sync Project with Gradle Files**, потім **Run**.

Виправлено завантаження списку роздач UA Kino, додано вбудований програвач і узгоджено форму карток. Збірка й 60 JVM-тестів пройшли; Lint — без помилок. Реальне відтворення на TV ще потребує перевірки. Запит самого торрент-дескриптора у хмарі повернув перевірку браузера Cloudflare HTTP 403; отримання списку роздач перевірене окремо.
